# Issue forms

Generic GitHub issue forms. Copy the files you need to `.github/ISSUE_TEMPLATE/` in your
repository and adapt the `labels` and the dropdown options.

| File | Use for |
|------|---------|
| [`task.yml`](task.yml) | A piece of work with a goal, tasks and a definition of done |
| [`bug.yml`](bug.yml) | Something wrong, outdated or inconsistent |

Labels used by the forms must exist in the repository, or GitHub ignores them.
